Description

A scalable backend API for a healthcare appointment platform that enables:

Patients to register and book appointments.
Doctors to manage their profiles and schedules.
Users to leave reviews and ratings.
Secure authentication and authorization.
Data validation for all incoming requests.
Technologies Used
Node.js
Express.js
MongoDB
Mongoose
Postman
Features
RESTful API Architecture
JWT Authentication
Role-based Authorization
Doctor and Patient Management
Appointment Scheduling
Reviews and Ratings
File Upload Support
Validation Middleware
Modular Service Layer
